# Карта коммерческой недвижимости СПб

Данные зашифрованы AES-256-GCM с ключом из пароля через PBKDF2 (100 000 итераций).
Без правильного пароля браузер не сможет прочитать `points.enc.json` — там
только зашифрованный шум.

## Содержимое
- `index.html` — карта + страница ввода пароля
- `points.enc.json` — зашифрованный массив объектов недвижимости
- `.nojekyll` — отключить Jekyll-обработку на GitHub Pages

## Как пересобрать
Из корня основного проекта (`Офис/`):

```
node scripts/deploy_map.mjs --regenerate
```

`--regenerate` пересоберёт `web/points.js` из БД, потом зашифрует.
Без флага — зашифрует существующий `points.js` (быстрее, если БД не менялась).
